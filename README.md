# Sherlok blog site (test)

Astro's blog template, published on GitHub Pages, used to test the Sherlok Blog Writer's GitHub connector end to end.
The content schema in `src/content.config.ts` also accepts the fields the Sherlok writes (`date`, `image`, `image_alt`, ...).

In the Sherlok: posts in `src/content/blog/{slug}.md`, images in `public/images/blog`, images address `/sherlok-blog-site/images/blog`.
